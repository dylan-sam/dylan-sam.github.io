- [**Piano Practice Companion**](https://github.com/dylan-sam/piano-practice-companion) : Piano Practice Companion est une application web et mobile open source qui vous permet de pratiquer votre instrument de musique à l'aide de pistes d'accompagnement et de partitions provenant de la base de données ChoCo (qui inclut les forums iReal Pro). Vous pouvez lire une piste et utiliser ces mêmes morceaux pour travailler la reconnaissance à l'oreille des progressions d'accords ou la lecture à vue. [Essayez la démo web ici](https://dylan-sam.github.io/piano-practice-companion/).
